# tools/

The Researcher's tools, exposed to Hermes via an **MCP server**. Build fresh.

Pick 2-3 *real* tools that make a good live demo and a genuine Researcher→Writer story, e.g.:
- a web/search or fetch tool,
- a small structured lookup/calculator,
- (optional, trade-flavoured for PST.AG) an HS-code / tariff lookup.

Remember: the tool's **docstring/description is what teaches the model when to call it** (not SOUL.md).
Same tools stay usable by both agents. See `../HANDOFF.md` §4–§5.
